i Help & Quick Guide
  • Sign In: Enter the Sign In code before generating the report.
  • Rate per KG: Enter the rate charged for 1 KG. This value is saved with the report and included in the Excel export.
  • USD → ETB Currency Rate: Enter the current exchange rate used for the report.
  • EMD Records: Paste one or multiple EMD records into the input box.
  • Generate & Add Report: Processes the pasted EMD records and adds them to the report.
  • Download Excel: Exports the generated report to an Excel file.
  • Clear Input: Removes the text currently pasted into the EMD input box.
  • Clear All: Deletes the current report data and resets the report fields.
